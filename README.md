# مدیریت کافه لیندا (Android / Flutter)

اپلیکیشن فارسی و راست‌چین برای مدیریت پایه کافه، با ذخیره‌سازی محلی روی خود گوشی (بدون نیاز به اینترنت در زمان استفاده).

## امکانات نسخه فعلی
- داشبورد فروش روزانه، هزینه روزانه، تعداد کالاها و هشدار موجودی کم
- ثبت کالا و منو با قیمت فروش، بهای تمام‌شده و موجودی
- ثبت فروش از روی منو و کسر خودکار موجودی کالا
- ثبت هزینه‌ها و درآمدهای متفرقه
- ثبت بدهی و طلب و ثبت پرداخت/دریافت مرحله‌ای
- ثبت کارکنان و حقوق ماهانه
- گزارش ساده فروش، هزینه و مانده درآمد/هزینه

## ساخت فایل APK با GitHub
1. وارد GitHub شوید و یک مخزن جدید بسازید؛ مثلاً `linda-cafe-manager`.
2. فایل‌های این پوشه را در مخزن آپلود کنید (محتویات پوشه، نه خود پوشه‌ی مادر).
3. از زبانه **Actions**، گردش‌کار **Build Android APK** را باز کنید و روی **Run workflow** بزنید. با هر بار push به شاخه `main` نیز خودکار اجرا می‌شود.
4. پس از اتمام موفق، وارد اجرای workflow شوید و از قسمت **Artifacts** فایل `linda-cafe-android-apk` را دانلود کنید. فایل داخل آن `app-release.apk` است.

## اجرای محلی (اختیاری)
Flutter SDK و Android SDK نصب کنید، سپس در ریشه پروژه اجرا کنید:
```bash
flutter pub get
flutter run
flutter build apk --release
```

## نکات مهم
- داده‌ها روی همان گوشی ذخیره می‌شوند؛ در این نسخه همگام‌سازی ابری یا انتقال خودکار بین چند گوشی وجود ندارد. حذف برنامه ممکن است داده‌های محلی را پاک کند؛ از اطلاعات مهم نسخه پشتیبان بگیرید.
- این نسخه، پایه قابل توسعه است؛ چاپ فاکتور، خروجی Excel/PDF، مدیریت رسپی و کسر مواد اولیه، خرید از تأمین‌کننده، شیفت صندوق، ورود کاربران و پشتیبان‌گیری هنوز پیاده‌سازی نشده‌اند.
- گزارش سود فعلی ساده است و بهای تمام‌شده، حقوق و هزینه‌های ثبت‌نشده را خودکار محاسبه نمی‌کند.
